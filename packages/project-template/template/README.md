# CORE Studio app

A standard Vite + React + React Router + Tailwind CSS app created by CORE AI Design Studio.

```bash
npm install
npm run dev
```

- `src/pages/<page>/` — one folder per page; the route table in `src/app/routes.ts` is generated from `core.project.json`.
- `src/layouts/` — shared layouts.
- `src/components/` — shared components.
